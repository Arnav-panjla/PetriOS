# carousel_description

Fixed/static carousel package using the supplied CAD STL meshes.

Included:
- carousal_base.stl
- carousal_stand.stl
- holder_plates.stl

Not included:
- petri.stl
- carrousal_x-channel.stl

Build:
  cd ~/ros2_ws
  source /opt/ros/humble/setup.bash
  colcon build --symlink-install
  source install/setup.bash
